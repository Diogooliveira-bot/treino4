# Treino 4 — PWA

## Publicar
1. Extraia o ZIP.
2. Envie a pasta para Vercel (ou qualquer hospedagem HTTPS).
3. Abra o link no Android pelo Chrome.
4. Use o botão "Instalar" quando aparecer ou o menu do navegador > "Adicionar à tela inicial".

## Recursos
- 4 treinos fixos em sequência.
- Indicação automática do próximo treino.
- Registro de carga e repetições por série.
- Cronômetro: 30s, 45s, 1min, 1min30 e 2min — fixo na tela; toque no tempo para iniciar.
- Check nos exercícios concluídos com contador.
- Histórico e relatório de evolução das cargas.
- Backup/restore em JSON.
- Funciona offline após o primeiro carregamento.
- Histórico inicial já incluído com os treinos registrados até 22/08/2026.

## Observação
Os dados são salvos localmente no aparelho/navegador. Use "Backup" para exportar periodicamente.
